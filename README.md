# pigmint

An opinionated color engine that takes a brand's color intent and produces framework-portable design tokens with accessibility receipts baked in.

- Architecture and ADRs: [`plan.md`](./plan.md)
- Spec artifacts (Step 0): [`spec/`](./spec/)

Pigmint is scoped as a local-only, personal-use tool (ADR-020). Current status: **Step 0 — spec composition**. No implementation code yet.
